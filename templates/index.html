Princípio de Estabilidade: O Critério de Nyquist determina estabilidade através da relação $Z = N + P$, onde $P$ é o número de polos de malha aberta no semiplano direito (RHP), $N$ é o número de envoltórios horários no ponto crítico $(-1 + j0)$, e $Z$ é o número de polos instáveis em malha fechada. Para estabilidade, é estritamente necessário que $Z = 0 \iff N = -P$.
