Sistemas de Teste para Análise Comparativa de Estabilidade

Modelagem matemática e caracterização analítica dos quatro cenários de teste definidos na Fase 1 do projeto. Cada planta explora propriedades dinâmicas desafiadoras: polos instáveis no semiplano direito, zeros de fase não-mínima e termos transcendentais de atraso puro de transporte em redes.

SISTEMA A

Padrão (3ª Ordem Estável)

Sistema de terceira ordem estável em malha aberta, com três polos reais no semiplano esquerdo.

$$G_A(s) = \frac{K}{(s+1)(s+2)(s+3)}$$
  • Polos MA: $s = -1, -2, -3$ ($P = 0$)
  • Zeros MA: Nenhum ($m = 0$)
  • Faixa de Estabilidade: $0 < K < 60$ ($K_{crit} = 60$)
  • Comportamento Nyquist: Não envolve $(-1, 0)$ para $K < 60$ ($N = 0, Z = 0$).

SISTEMA B

Instável em Malha Aberta

Representa sistemas inerentemente instáveis, como o pêndulo invertido ou levitador magnético linearizado.

$$G_B(s) = \frac{K}{(s-1)(s+2)(s+5)}$$
  • Polos MA: $s = +1, -2, -5$ ($P = 1$ polo no RHP!)
  • Critério de Nyquist: Exige $N = -1$ (envoltório anti-horário) para $Z = 0$.
  • Faixa de Estabilidade: $10 < K < 28$. Para $K < 10$ ou $K > 28$, o sistema é instável.
  • Dificuldade de Bode: Não trivial de interpretar diretamente sem Nyquist.

SISTEMA C

Fase Não-Mínima

Planta contendo zero no semiplano direito. Gera resposta inversa (*undershoot*) e limite estrito no ganho.

$$G_C(s) = \frac{K(s-2)}{(s+1)(s+3)(s+5)}$$
  • Zeros MA: $s = +2$ (Zero no RHP)
  • Efeito Temporal: Resposta ao degrau inicia na direção negativa antes de subir.
  • Efeito em Frequência: Atraso de fase severo sem redução de ganho.
  • Faixa de Estabilidade: $0 < K < 7.5$.
Simular no Workbench
SISTEMA D

Atraso de Transporte

Modela sistemas controlados por redes de dados (NCS) ou processos térmicos e químicos com tempo morto $\tau$.

$$G_D(s) = \frac{K e^{-\tau s}}{(s+1)(s+2)}, \quad \tau = 0.5\text{ s}$$
  • Termo Transcendental: $e^{-\tau s}$ introduz defasagem linear $-\omega \tau$ radianos.
  • Tratamento Nyquist: Exato em frequência; diagrama espirala em direção à origem.
  • Tratamento Algébrico: Impossível diretamente; exige aproximação racional de Padé.
  • Degradação da Margem: Limite crítico de ganho e latência reduzidos drasticamente.
