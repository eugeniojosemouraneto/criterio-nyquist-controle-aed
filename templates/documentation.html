1. Arquitetura do Software e Princípios de Projeto

O projeto foi desenhado sob o princípio de transparência algorítmica total: nenhum pacote fechado de teoria de controle (como python-control, scipy.signal ou toolboxes comerciais) foi utilizado para realizar cálculos de estabilidade, resposta temporal ou diagramas de frequência.

2. Módulos do Núcleo Computacional

core/polynomial.py — Manipulação de Polinômios e Raízes

Implementa a classe Polynomial com avaliação numérica estável via algoritmo de Horner ($O(n)$ operações), diferenciação analítica, convolução para multiplicação, e extração de raízes através da matriz companheira de Frobenius de dimensão $(n \times n)$, cujos autovalores correspondem rigorosamente às raízes do polinômio mônico normalizado (OGATA, 2010).

core/routh_hurwitz.py — Critério de Routh-Hurwitz e Singularidades

Monta a Tabela de Routh para o polinômio característico de malha fechada $q(s) = 0$. Trata automaticamente os dois casos especiais clássicos documentados em Ogata (2010) e Nise (2017):

  • Primeira coluna nula: Introduz perturbação infinitesimal $\epsilon = 10^{-8}$ e preserva a continuidade dos determinantes.
  • Linha inteira nula: Detecta raízes simétricas (como eixos puramente imaginários $\pm j\omega$), forma o polinômio auxiliar $A(s)$ da linha imediatamente anterior e substitui a linha nula pelos coeficientes da derivada analítica $dA(s)/ds$.
  • Contagem de mudanças de sinal: Quantifica exatamente os polos no semiplano direito ($P_{rhp}$).

core/nyquist.py — Mapeamento Conforme e Winding Number

Avalia a resposta em frequência polar $G(j\omega)H(j\omega)$. Constrói o Contorno de Nyquist completo $\Gamma_s$ com indentação infinitesimal de raio $\epsilon$ para contornar eventuais polos na origem ($s = 0$). Aplica o Princípio do Argumento de Cauchy com cálculo do Winding Number $N$ por meio da integração angular total $\Delta \theta / 2\pi$ e validação cruzada com o teste de interseção de raios geométricos horizontais. Avalia a estabilidade através da relação fundamental $Z = N + P$.

core/root_locus.py — Lugar Geométrico das Raízes

Calcula analiticamente o número de assíntotas $n - m$, seus ângulos $\phi_a = (2k+1)180^\circ/(n-m)$, o centroide $\sigma_a = (\sum p - \sum z)/(n-m)$, e os pontos de dispersão (*breakaway*) resolvendo $D'(s)N(s) - D(s)N'(s) = 0$. Rastreia os ramos para uma grade adaptativa de ganhos $K$ com algoritmo de continuidade por vizinho mais próximo.

core/simulation.py — Simulação Temporal Runge-Kutta 4

Converte a planta para espaço de estados na forma canônica controlável e realiza a integração numérica RK4 de quarta ordem. Para sistemas com atraso puro de tempo $\tau$, utiliza uma fila circular de buffer contínuo que armazena a saída $y(t - \tau)$ sem necessitar de aproximações polinomiais. Extrai automaticamente o tempo de subida ($t_r$), tempo de pico ($t_p$), sobressinal percentual ($\%OS$) e tempo de acomodação ($t_s$, critério de 2%) segundo Nise (2017).

core/cross_validation.py — Validação Cruzada (Fase 3 do Projeto)

Executa o confronto direto entre os cálculos produzidos pelo motor próprio (desenvolvido a partir dos primeiros princípios na Fase 2) e as funções consolidadas da biblioteca python-control (control.margin, control.poles e control.step_response) e scipy.signal. Atesta que as margens de ganho e fase, frequências de cruzamento e valores temporais coincidem com discrepância inferior a $0.05\%$.

3. Especificação das APIs RESTful

POST /api/analyze

Recebe a definição da planta e retorna todos os dados calculados de Nyquist, Routh, Root Locus, Bode, Resposta Temporal e Padé.

// Exemplo de Payload JSON de Entrada
{
  "num": [1.0],
  "den": [1.0, 6.0, 11.0, 6.0],
  "gain": 20.0,
  "tau": 0.0
}
GET /api/benchmark/<benchmark_id>

Retorna a configuração completa dos benchmarks: sistema_a, sistema_b, sistema_c ou sistema_d.

POST /api/scalability

Executa a bateria de benchmarks de escalabilidade de tempo e erro de Wilkinson para ordens arbitrárias (ex: {"orders": [3, 5, 10, 20]}).

4. Suíte de Testes Unitários Automatizados

O projeto inclui 27 testes unitários automatizados organizados em 7 arquivos na pasta tests/, garantindo cobertura completa das rotinas matemáticas e das rotas HTTP:

  • tests/test_polynomial.py (6 testes): Avaliação de Horner, derivadas, convolução e extração de raízes.
  • tests/test_routh_hurwitz.py (5 testes): Polinômios estáveis, instáveis, Caso Especial 1 ($\epsilon$) e limites de ganho de malha fechada.
  • tests/test_nyquist.py (4 testes): Contagem de envoltórios $N$, sistemas estáveis, instáveis em malha aberta ($P = 1, N = -1$) e invariância de magnitude no atraso puro.
  • tests/test_root_locus.py (3 testes): Cálculo de assíntotas, centroide $\sigma_a$, ângulos $\phi_a$ e pontos de dispersão.
  • tests/test_bode_and_delay.py (5 testes): Margens de Bode, aproximações analíticas de Padé [1/1] e [2/2], e simulação temporal RK4.
  • tests/test_benchmarks.py (4 testes): Integridade dos quatro sistemas de benchmark e escalabilidade.
  • tests/test_api.py (5 testes): Teste de integração das rotas web e endpoints JSON.

5. Guia Passo a Passo de Reprodutibilidade

Siga as etapas abaixo para clonar, instalar dependências, executar os testes e inicializar a aplicação web em qualquer ambiente Windows, Linux ou macOS:

Passo 1: Pré-requisitos

Certifique-se de possuir o Python 3.10 ou superior instalado no seu sistema.

python --version

Passo 2: Instalação das Dependências

Instale os pacotes mínimos requeridos pelo projeto (Flask, NumPy e Pytest):

pip install -r requirements.txt

Passo 3: Execução da Suíte de Testes Unitários

Execute todos os testes automatizados para verificar a integridade matemática do núcleo:

# Via pytest:
pytest

# Ou via unittest padrão da biblioteca padrão do Python:
python -m unittest discover tests

Passo 4: Inicialização do Servidor da Aplicação

Inicie o servidor web local com:

python app.py

Passo 5: Acesso ao Dashboard Interativo

Abra seu navegador preferido no endereço:

http://127.0.0.1:5000
